KSISU REAL-DATA EVIDENCE WORKBENCH — START HERE

1) Install:
   python -m pip install -r requirements.txt

2) Run the automated test:
   SELF_TEST.bat
   It must end with PASS: pipeline completed without exception.

3) Run the baseline analysis:
   python run_gap.py
   or run run.bat

4) Judge-demo workflow:
   A. Open the GUI.
   B. Click Run Proxy Baseline.
   C. Open District Priority: explain this is a data-onboarding / VOI ranking, not a fake gap leaderboard.
   D. Click Load DGT 2026 Real Supply.
   E. Click Run With Loaded Supply.
   F. Open Gap Results and Validation & Linkage.
   G. Show the real DGT provisional supply basis and the NEEDS DATA policy gate.

5) Real public supply already bundled:
   The package includes the uploaded DGT CTS-2026 provisional dynamic seat matrix and an extracted Karnataka district×ITI×trade dataset. Use Load DGT 2026 Real Supply to demonstrate it. It contains 1,734 Karnataka trade rows, 588 ITIs and 45,416 provisional seats; 39,984 seats map into the NCO 72/74 pilot crosswalk.

6) Do not enter invented numbers. The DGT source is real public evidence but provisional and incomplete for the analytical geography used here. Kodagu and Vijayanagara are absent from the extracted DGT rows, and 12.0% of published seats are outside the pilot NCO crosswalk.

7) Source discipline:
   - observed = directly from public source
   - proxy = derived using an explicit rule
   - prior = analyst assumption pending better data
   - partial_floor = real district evidence but incomplete coverage; observed seats are a lower bound, remainder is uncertain

8) Policy discipline:
   Proxy-only and partial-actual rows stay NEEDS DATA. Only complete district-actual cells can become PROVISIONAL GAP / PROVISIONAL SURPLUS.
