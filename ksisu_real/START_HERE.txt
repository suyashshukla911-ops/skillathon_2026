KSISU REAL-DATA GUI PILOT - EXACT TEST STEPS
=============================================

1) Extract this ZIP to a NEW folder.
   Example:
   Desktop\KSISU_REAL_GUI_FINAL\ksisu_real\

2) Open the "ksisu_real" folder in VS Code.

3) Install packages ONCE:
   python -m pip install -r requirements.txt

4) Run the automated self-test:
   double-click SELF_TEST.bat
   Expected:
     PASS: 31 districts
     PASS: 93 district×occupation rows
     PASS: year-aware results present
     PASS: shared-draw Monte Carlo intervals present
     PASS: policy decision gate present
     PASS: pipeline completed without exception

5) Start the GUI:
   double-click run.bat
   OR:
   python ksisu_gui.py

6) In the GUI, DO NOT type fake numbers.
   First test uses the bundled public research inputs.

7) Click "Run Analysis".
   Expected status:
     31 districts • 93 district×occupation rows • 0 provisional gaps • 93 need data

   IMPORTANT:
   The policy-facing result stays NEEDS DATA in proxy-only mode.
   This is intentional. Mathematical signal != policy finding.

8) Open "Gap Results".
   Review:
     District
     NCO 72 / 74 / 81
     P10 / Median / P90
     Interval width
     Confidence
     Decision
     Supply basis

9) Open "District Priority".
   This is the main policy output in proxy-only mode:
     SCI
     Annual openings
     VOI
     Confidence
     Priority rank

10) Open "Sensitivity".
    Show which assumption changes the ratio most.

11) Open "Validation & Linkage".
    Show:
      district matching recovery
      duplicate recovery test
      sanity check
      interval-shrink area

12) LIVE JUDGE DEMO:
    Obtain an authoritative district/trade ITI seat CSV from NCVT MIS,
    DGT, or Karnataka Skill Department.

    Accepted minimum columns:
      district,nco_group_2digit,seats

    OR:
      district,trade,seats

    Then click:
      "Load Actual District Supply"
      select the real CSV
      "Run Analysis"

13) Compare Tumakuru and Kalaburagi (or whichever districts your real
    extract covers). Rows with actual supply will show:
      supply_basis = district-actual
      decision_status = PROVISIONAL GAP / PROVISIONAL SURPLUS / NEEDS DATA

    The model uses the same method; only the evidence source changes.

14) Never submit proxy-only district gap labels as official findings.
    The competition narrative should be:
      public data can produce a transparent prior;
      KSISU should collect better district data first where VOI is highest;
      once district-actual data arrives, the interval becomes narrower.

15) CLI reproducibility:
    python run_gap.py
