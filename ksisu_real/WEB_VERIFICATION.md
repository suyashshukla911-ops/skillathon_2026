# Web verification notes - 16 Oct 2026

These are the official/public pages checked while strengthening the pilot.

1. **LGD**: the Government of India Local Government Directory has a Download Directory interface with an option for all districts of a state and XLS/CSV-style outputs. Refresh the live Karnataka export before final filing.
2. **Udyam district employment**: the OGD resource for Karnataka Udyam registration units with employment details is public and owned by Karnataka Industries and Commerce / Directorate of Industries and Commerce.
3. **ASI**: MoSPI ASI Summary Results 2022-23 reports Karnataka selected-manufacturing persons engaged of 1,166,555.
4. **NCVT MIS**: the current ITI Count page reports Karnataka with 1,467 ITIs, 70 trades and 216,772 seats available in 2022. NCVT MIS also exposes downloadable district/trade/seat fields in ITI extracts; this is the preferred supply input for the GUI.
5. **PLFS**: MoSPI publishes the PLFS 2022-23 annual report and NCO occupation tables. Unit-level occupation-by-industry analysis may require microdata access/registration, so this pilot labels the occupation mix as a prior until observed Karnataka microdata is loaded.

This file is a research trace, not a substitute for checking the original source documents before submission.
